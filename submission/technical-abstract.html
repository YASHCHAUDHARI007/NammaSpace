Capture SOP and source controlRound 1 · Technical abstract

Record a stable, overlapping room pass

The repeat-capture SOP has seven actions. Select one room. Record one continuous video with one lens. Keep people out and use steady light. Walk slowly with translation. Show walls, floor edges, ceiling, and furniture from several positions. Avoid fast pans. Keep the raw video and checksum. Check that the camera route is continuous before training.

Frame 80 from C5306.MP4 shows the stage steps, floor, desks, and chairs. The camera faces down, which limits upper-room coverage.

Reconstruction and quality controlRound 1 · Technical abstract

Validate depth against the video camera solve

Sequential PyCOLMAP reconstruction registered 198 of 198 frames in one model with 59,929 sparse points. Its mean reprojection error was 0.754 pixels. The median adjacent camera step was 0.141 model units and the maximum was 0.171.

VGGT inferred depth and camera predictions for 25 sampled frames. We fitted each depth map to sparse points from the same video. All 25 had a positive depth scale. Median relative depth error was 1.14% at matched sparse points. VGGT camera poses were less consistent, so training used PyCOLMAP poses and VGGT depth points.

Training and export

  1. Filter the sparse cloud to 58,344 starting points. Add 51,800 depth points that pass confidence and room-envelope checks.
  2. Train Nerfstudio Splatfacto for 20,000 steps on the NST GPU node. Disable camera optimization and scale regularization.
  3. Fit the visible floor using the same video. Define the median camera clearance as one arbitrary scene unit.
  4. Remove distant outliers and export 873,736 records in the standard 32-byte .splat layout.
Relative scale
The fitted floor sets Y = 0. No physical length was measured. Positions and routes use scene units.
Browser result
The 26.66 MiB asset loads in the desktop viewer. The captured aisle supports free roaming and a short front route.

Visual limits

The floor, stage steps, desks, and chairs are recognizable. A dark patch remains near the upper front wall. The ceiling and upper walls have weak coverage because the camera points down. Extra training cannot restore surfaces that the source did not record.

Held-out image scores are PSNR 31.05, SSIM 0.929, and LPIPS 0.174. Test images are nearby frames from the same video, so these scores can overstate quality from new viewpoints. There is no measured room size or mobile performance result.

Web viewer and reproducibilityRound 1 · Technical abstract

Walk through the captured aisle

The C5306 room is the app's default scene. Visitors use WASD or arrow keys to move, and the mouse to look. The viewer streams the splat, shows load progress, and has a reset control. It reports camera positions and route lengths in scene units.

Search finds one front-aisle point of interest. Its route stays near recorded camera positions. Walk limits are visual estimates. The app does not claim verified furniture collision for this scene.

Reproduce and inspect

The repository contains the frame and camera reconstruction pipeline, VGGT depth inference and validation, floor calibration, and splat export scripts. The C5304 model remains available as an earlier comparison scene.

npm ci → npm test → npm run build → npm run start
Open the site in a WebGL browser. The full reconstruction needs the original C5306.MP4 source, which is not stored in Git.

Open-source tools and credits
