## Using historical instructions and results

- **Commands and paths:** Some restored guides refer to scripts, source videos (`assets/C5304.MP4`, `assets/C5306.MP4`, `assets/C5307.MP4`), sample frames, generated assets, or submission videos that are not in main. Inspect those references in the pinned source snapshot. This commit restores documentation only. It does not restore the old application, training scripts, or capture assets.
- **Relative links:** Links inside the restored files are unchanged. They point to paths relative to each file's original location. Some resolve to main's current files, and some no longer resolve. Use the original-source links above to follow them as written.
- **Results:** Treat measured results, test outcomes, and statements such as "the default scene" or "in the main branch" as true only for the source snapshot. A new run must record its own commit, environment, output, and date.
